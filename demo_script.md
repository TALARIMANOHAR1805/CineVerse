# CineVerse Demo Video Script

**[0:00-0:15] Scene 1: Search & Discovery**
Visual: User types "Iron Man" into the search bar. Real-time results populate seamlessly.
Action: The user highlights a movie card to show the clean UI.
Voiceover: "Welcome to CineVerse. Finding your next watch is as fast as a single search, instantly pulling results across both movies and anime."

**[0:15-0:30] Scene 2: Before You Watch (Timeline)**
Visual: User clicks the movie card. The detail modal opens to the Timeline tab.
Action: Smooth vertical scroll through the prequel and sequel cards (e.g., showing Iron Man 1 → 2 → 3).
Voiceover: "Not sure where a movie fits in? Our 'Before You Watch' timeline pulls from TMDB's franchise collections, placing your film exactly where it belongs — no spoilers."

**[0:30-0:45] Scene 3: Six-Degrees Pathfinding (Graph)**
Visual: User switches to the Graph Connections tab.
Action: The UI dynamically traces the relationship path between Iron Man and another film using Neo4j shortest-path algorithms.
Voiceover: "Curious about actor crossovers? Our Six-Degrees feature dynamically maps the connections between franchises and shared cast members."

**[0:45-1:00] Scene 4: Spoiler-Shield**
Visual: User searches for an ongoing anime series (e.g., One Piece). The detail modal opens.
Action: The spoiler-shield toggle is checked, completely hiding the plot synopsis.
Voiceover: "Still catching up on a show? The Spoiler-Shield heuristic evaluates your current episode progress and safely suppresses the synopsis so nothing gets ruined."

**[1:00-1:15] Scene 5: Vibe Match**
Visual: User clicks the "Vibe Match" feature from the navigation.
Action: Selects "Neon Cyberpunk" and the results instantly populate with aesthetically matched movie posters.
Voiceover: "Looking for a specific mood? Vibe Match uses real-time color extraction to instantly pair you with movies that fit your aesthetic. Try CineVerse today."
